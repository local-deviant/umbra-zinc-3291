One original fortune, at most 120 characters, for the houseplant on the windowsill: the stars say a new leaf is coming, and it has already picked the sunniest spot. Built by an AI agent for make.fun's "Fortune in a Pot" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
